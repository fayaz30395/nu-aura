# ADR-004 — Contract-first API: OpenAPI (SpringDoc) → Orval-generated typed TanStack Query clients

> Reverse-engineered ADR documenting a decision already realized in the codebase.
> See [[Architecture-Decisions]] · [[APIs]] · [[Components]] · [[CI-CD]].

## Status

**Accepted** — the frontend data layer is generated from the backend OpenAPI spec.
Verified against `frontend/orval.config.ts`, `frontend/lib/api/orval-mutator.ts`,
`frontend/lib/generated/api/` (generated output), `frontend/openapi-snapshot.json`,
and `backend/.../common/config/OpenApiConfig.java` (SpringDoc).

## Context

The backend exposes ~179 `@RestController`s across ~67 bounded contexts. The
frontend ([[Nu-HRMS]], [[Nu-Hire]], [[Nu-Grow]], [[Nu-Fluence]]) consumes nearly all
of them. Hand-writing and hand-maintaining typed fetch hooks for hundreds of endpoints
is error-prone: request/response shapes drift from the server, breakages surface only at
runtime, and every backend DTO change is a manual frontend chore.

The team needed the **server contract to be the single source of truth** for client
types, with the client regenerated mechanically so type drift is caught at compile time
rather than in production.

## Decision

Adopt a **contract-first pipeline**: SpringDoc produces the OpenAPI document at
`/v3/api-docs`; **Orval** generates the entire frontend data layer from it.

`frontend/orval.config.ts` configures:

- **input**: `process.env.API_DOCS_URL ?? 'http://localhost:8080/v3/api-docs'` — live
  backend in dev, or a committed snapshot (`openapi-snapshot.json`) in CI.
- **`mode: 'tags-split'`** — one file per OpenAPI tag (Auth, Employees, Leave
  Management, …) so churn stays local to each domain.
- **`client: 'react-query'`** + **`httpClient: 'axios'`** — emits typed
  `@tanstack/react-query` hooks (`useFooQuery`, `useFooMutation`), already the
  project's server-state layer ([[ADR-001]]-aligned: API layer stays the contract).
- **`mutator`** routing every generated request through the existing `apiClient`
  (`lib/api/orval-mutator.ts` → `lib/api/client.ts`), so generated calls inherit
  httpOnly-cookie auth, the 401-refresh mutex, CSRF, and tenant headers ([[ADR-005]]).
- Output `lib/generated/api/` is **regenerated on demand** (gitignored generated
  source; a committed `openapi-snapshot.json` feeds deterministic CI codegen).

Generation runs via `npm run api:generate` against a running backend, or against the
snapshot in CI.

## Consequences

### Positive

- **Compile-time contract safety** — backend DTO changes that break the client show up
  as TypeScript errors after regeneration, not as runtime 4xx/parse failures.
- **No hand-written API plumbing** — hundreds of typed hooks are generated, eliminating
  copy-paste drift across ~264 pages.
- **Localized churn** — `tags-split` confines regeneration diffs to the changed domain's
  file.
- **Auth/tenant invariants preserved** — the mutator funnels all generated traffic
  through the one hardened Axios client, so cookie auth, refresh, CSRF, and tenancy are
  never re-implemented per call.

### Negative

- **Generation step in the loop** — the client must be regenerated when the contract
  changes; a stale generation hides new endpoints or shape changes.
- **Snapshot can lag** — `openapi-snapshot.json` must be refreshed or CI codegen tests
  an out-of-date contract.
- **Generated ergonomics are fixed by Orval** — hook naming/shape follow the generator's
  conventions, not hand-tuned APIs; deviations require overrides.
- **Spec quality gates client quality** — missing tags, vague schemas, or untyped
  responses on the backend propagate into weaker generated types.

## Alternatives Considered

- **Hand-written Axios/React Query hooks** — rejected: unmaintainable at this endpoint
  count and prone to silent drift.
- **GraphQL** — rejected: would require a parallel schema layer over an already-large
  REST surface; REST + OpenAPI already exists and is documented.
- **gRPC / generated gRPC-web clients** — rejected for a browser-first internal app;
  REST + cookie auth + Next.js proxy is simpler for the single-origin model.
- **tRPC** — rejected: assumes a TS backend; this backend is Java/Spring.
