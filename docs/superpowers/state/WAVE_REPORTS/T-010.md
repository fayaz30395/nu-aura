# T-010 - Real-time WebSocket Contract

Status: complete

## Files Changed

- `backend/src/main/java/com/nulogic/common/websocket/WebSocketAuthTokenHandshakeInterceptor.java` - copies access-token cookies from the SockJS/WebSocket handshake into server-side session attributes.
- `backend/src/main/java/com/nulogic/common/websocket/WebSocketSecurityConfig.java` - authenticates STOMP CONNECT with either a bearer header or handshake cookie, uses JWT `userId` as the WebSocket principal, and preserves tenant-topic authorization.
- `backend/src/main/java/com/nulogic/infrastructure/websocket/WebSocketConfig.java` - registers the handshake interceptor on `/ws`.
- `frontend/lib/contexts/WebSocketContext.tsx` - subscribes to `/user/queue/notifications`, `/topic/tenant/{tenantId}/notifications`, `/topic/announcements`, and shutdown notice paths instead of unsupported legacy topics.
- `frontend/lib/services/websocket.ts` - aligns the standalone service subscriptions with backend delivery destinations.
- `backend/src/test/java/com/nulogic/common/websocket/WebSocketAuthTokenHandshakeInterceptorTest.java` - covers hardened and legacy access cookie extraction.
- `backend/src/test/java/com/nulogic/common/websocket/WebSocketSecurityConfigTest.java` - covers cookie-backed CONNECT, user principal mapping, allowed user queue, allowed tenant topic, and rejected cross-tenant/legacy user-topic subscriptions.
