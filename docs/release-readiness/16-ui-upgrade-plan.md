Date 2026-11-15. Planning only; no source changed. Evidence: `03..06-*-results.md`, `14-keka-parity.md`,
`15-known-defects.md`, `evidence/defects-*.md`, `evidence/fe-static-results.md`, `evidence/fixes-*.md`, and the

## 1. Current-state diagnosis

1. Static gates are green: `tsc --noEmit` 0 errors, eslint 0 problems, 2,609 vitest tests pass (`evidence/fe-static-results.md`). Next is now 16.4.6 in `node_modules` (`package.json` pins `^16.2.7`); the audit-fix bump is unverified by a build.
2. Permission-aware UI exists and is well used: `PermissionGate` in 157 `app/` files, `usePermissions` in 263; nav is filtered by `components/layout/navAccess.ts`. Gaps are local, not structural (e.g. `app/holidays/page.tsx:286` gates "Add Holiday" on a role flag, `app/fluence/wiki/page.tsx:246-253` shows "New Page" to roles with no KNOWLEDGE permission, `06-fluence-results.md` U01).
3. Two UI defects come from the FE ignoring data it has or lacks: `app/payroll/_components/types.ts:57-61` re-wraps date-only strings in `new Date()` before calling the timezone-safe `lib/utils/format/date.ts:18-24` (period shifted one day, DEF-PAY-07); `lib/services/hrms/payroll.service.ts:122` maps `totalGrossAmount` that the backend entity `backend/.../domain/payroll/PayrollRun.java` never carries (Gross Rs 0.00; `PayrollController.java:95-100` returns the raw entity).
4. `app/me/attendance/_hooks/useMyAttendance.ts:36-46` keys "today" on the browser date while the server stores the tenant date (DEF-HRMS-08); a `GET /api/v1/attendance/today` endpoint already exists in the generated client (`lib/generated/api/attendance/attendance.ts:785`).
5. `app/fluence/wiki/page.tsx:78-83` reads `isLoading` only; a 403/500 renders an empty shell with no error state, even though `components/ui/QueryState.tsx` (`QueryErrorCard`) and `lib/utils/error-handler.ts:312-314` (403 message) exist.
6. Consistency drift: raw `<table>` in 47 `app/` files vs `ResponsiveTable` in 30; raw `<button>` in 187 files. `app/payroll/_components/PayrollRunsTab.tsx` has 0 responsive classes and raw buttons; `scripts/check-styling-drift.mjs` (`npm run lint:design-system`) already ratchets these anti-patterns incl. rule 10 (icon-only buttons without a name).
7. `styles/mantine-theme.ts:358` uses a nested `'&[data-active]'` key inside Mantine `styles`, which Mantine 9 no longer supports: the console error reported in DEF-HRMS-10 and NU-GROW-E2E-182.
8. `app/employees/_components/AddEmployeeFields.tsx:63-70` + `lib/validations/employee.ts:81` require `employeeCode` though the API auto-generates it (DEF-HRMS-10); `app/performance/reviews/_components/ReviewCard.tsx:73-76` shows 0.0/5.0 for a submitted self review because it reads only `overallRating` (DEF-GROW-13; `selfRating` exists on the type, `lib/types/grow/performance.ts:650`).
9. Keka-replacement surface is mostly present: My Space routes (`app/me/*`), `menuSections.tsx:243-252`, `app/me/dashboard/page.tsx` (time clock, leave balance, presence, holiday carousel). What blocks parity is backend: payroll register, arrears, bank advice, loan EMI, timesheet period lock are NOT IMPLEMENTED (`14-keka-parity.md` #11-13, #20-23, #29) and employees hold no KNOWLEDGE permission (DEF-FLUENCE-05).
10. Palette: `tailwind.config` names the primary "Lapis Blue" (`--accent: #244288`, `app/globals.css:117`). It is a muted navy, not a bright blue; changing it is a product decision (section 4), not a task.

## 3. Task list (one Haiku worker per task)

Conventions. Every task ends with: `cd frontend && npx tsc --noEmit && npx eslint <touched files> --max-warnings=0` plus the vitest file named in the row. New tests follow `app/me/payslips/page.test.tsx` / `components/auth/__tests__/PermissionGate.test.tsx` patterns (jsdom, `vi.mock` for hooks). "Indep" = disjoint files, can run in parallel with every other task in the same wave. No task adds a new shared component; use `components/ui/*`, `PermissionGate`, `QueryState`, `ResponsiveTable`, `Button`, `EmptyState`.

## 4. Needs a human product/design decision (not tasks)

- D1. Employee access to Fluence: grant WIKI_READ/BLOG_READ/SEARCH (+ WALL_POST/REACT/COMMENT) to EMPLOYEE only after DEF-FLUENCE-04 (draft/PRIVATE leak) is closed (`evidence/defects-fluence.md` DEF-05, `15-known-defects.md`). Until then the wiki UI is admin-only by design.
- D2. Palette: keep the Lapis Blue navy accent (`#244288`) or move to the muted house palette. Changing `--accent` touches every product rail colour; decide before any W3 colour work.
- D3. Payroll totals: `PayrollRun` has no gross/net columns. Either compute totals from payslips in `PayrollRunService` and expose a DTO (backend task), or drop the Gross column. W1-02 shows a placeholder meanwhile.
- D4. Keka parity screens with no backend: payroll register, arrears, bank advice, loan EMI, timesheet period lock, accounting export (`14-keka-parity.md`). UI work is pointless until an API exists; pick which land first.
- D5. `employeeCode` policy: auto-generate always, or allow HR override (W1-06 allows blank; confirm the format when supplied).
- D6. Maker-checker visibility: after the same-user process/approve block (`15-known-defects.md`), should the UI hide "Approve" for the processor or show it disabled with a reason?
- D7. Demo panel: `NEXT_PUBLIC_DEMO_MODE` is now opt-in; confirm the Vercel project env and whether any marketing/demo build still needs it.

## 5. Risks

- R1. Next 16.4.6 arrived via `npm audit fix` (lockfile only, `evidence/fixes-sec-fe.md`); no production build has run on it. Next 16 renamed middleware to `proxy.ts` and changes image/CSP defaults; W4-04 must run before W4-05 and before any deploy. `node_modules/next/dist/docs/` is the source of truth, not training data.
- R2. Backend fixes referenced here (V344 LEAVE:REJECT, V345 wiki read, PDF close, rate-limit bucket) are uncommitted in the working tree and the running jar is stale (`15-known-defects.md`). UI tests pass independently, but live verification needs a rebuilt backend.
- R3. `lib/generated/api/*` is gitignored and regenerated from `openapi-snapshot.json`; W1-03 depends on `/attendance/today` being in the snapshot. If absent, regenerate against a running backend first.
- R4. `ResponsiveTable` migrations (W2) change DOM structure; any Playwright spec selecting `table tbody tr` in `e2e/` for payroll pages will need updating. Grep `e2e/` for `/payroll` before merging W2.
- R5. `PayrollRun` arithmetic in `app/payroll/page.tsx:106-121` divides by `totalGrossAmount`; W1-02's `null` must not reach those lines unguarded (tsc will flag, but `?? 0` can hide a wrong KPI). Prefer showing the placeholder in KPI tiles too when every run is null.
- R6. Type-check drift: `typescript ^6.0.3` and `vitest ^5.0.4` are recent majors; keep acceptance commands exactly as written (`npx tsc --noEmit`, `npx vitest run <file>`) and do not add new config.
- R7. Rate limiting: the 5/min auth bucket (DEF-HRMS-01) made browser runs flaky; manual verification of W1/W3 in a browser should wait for the backend restart that carries the fix.
