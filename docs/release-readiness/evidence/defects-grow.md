# Grow defects (agent grow) - audit only, no code changed

Common root cause for 01-03: entities extend BaseEntity with `@Version Long version` (backend/src/main/java/com/nulogic/common/entity/BaseEntity.java:61-63) and services pre-assign `setId(UUID.randomUUID())` before `save()`. Spring Data sees a non-null id, calls merge, Hibernate 6 throws "Detached entity with generated id ... uninitialized version value 'null'" which the global handler returns as 400 DB_INTEGRITY_VIOLATION. `grep setId(UUID.randomUUID())` in application/ = 60 sites; other modules (hire/hrms/payroll) may be hit too.
