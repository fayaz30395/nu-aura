**Agent:** data | **Date:** 2026-06-10 | **Scope:** P0 entities — employee, leave request, attendance record, payroll run, approval, department/designation
**Method:** code-level verification (backend DTOs/services/repos, Flyway migrations, frontend Zod schemas). No runtime tests executed.

## What's solid (verified, no action)

- **Tenant isolation (7):** every P0 repo/service call seen filters `tenantId` (`findByIdAndTenantId`, tenant-spec AND-ed into Specifications); `TenantEntityListener` throws `SecurityException` on cross-tenant persist/update/delete; RLS is fail-closed RESTRICTIVE + `FORCE` on all `tenant_id` tables (V254), re-enforced for late tables (V255/V262), runtime role `NOBYPASSRLS`. SuperAdmin bypass is app-layer only, per design.
- **Concurrency (6):** leave balance mutations use `PESSIMISTIC_WRITE` (`getOrCreateBalanceForUpdate`); payroll uses per-period advisory lock (`PayrollPeriodLock`) + `findByTenantIdAndPeriodForUpdate` + status-machine guards (`approve()` throws unless PROCESSED); workflow `processApprovalAction` is idempotent (terminal-state + step-status checks → 409) with `@Version` optimistic backstop; payslip generation skips existing (`existsByTenantIdAndEmployeeIdAndPayPeriodYearAndPayPeriodMonth`); employee code allocation is an atomic Postgres sequence (V148).
- **Duplicates (2, partial):** V48 partial unique indexes (`WHERE is_deleted=false`) for employee_code/tenant, user email/tenant, department code/tenant; leave_balances unique (V26); 409/400 friendly mapping with DB internals suppressed.
- **Transactions (5):** `createEmployee` writes user+employee+audit in one tx; leave create reserves balance **before** save so failure rolls everything back; WebSocket/Kafka side effects deferred to `afterCommit`.
- **Audit (4, partial):** `@CreatedBy/@LastModifiedBy/@CreatedDate/@LastModifiedDate` populated via `AuditorAware`; audit-log entries on employee create, leave create/approve/reject/cancel, payroll process/fail, workflow actions, attendance check-in (`@Audited`). Gaps listed in DATA-10.
