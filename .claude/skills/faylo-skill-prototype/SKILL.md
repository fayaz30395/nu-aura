# faylo-skill-prototype

Auto-loads for `faylo-ui-designer` at Stage 07. A component spec is a text/markdown enumeration of components, props, and states — loading, empty, error, and success — not a visual mockup. Missing a state is treated as an incomplete spec, not an acceptable omission.
