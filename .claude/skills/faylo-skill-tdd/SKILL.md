# faylo-skill-tdd

Auto-loads for the Stage 10 implementation specialists. Writing the failing test from the FRD's acceptance criteria before the implementation is optional discipline, not a gate — Stage 11 checks the outcome (coverage and pass/fail), not which order the specialist wrote things in.
