# faylo-skill-git-safety

Auto-loads for every Stage 10 specialist and `faylo-devops-engineer`. Work happens on `feature/{ticket-id}-{slug}` in the target repo only — never in `faylo-sdlc` itself, and never on another engagement's branch, even to fix something small.
