# faylo-skill-adr

Auto-loads for `faylo-architect` at Stage 05. An ADR is raised (via Deviation Scan) only when a change needs to depart from an existing `architecture-principles/` rule — context, decision, consequences, one page. Silence (no ADR) means the existing principles already cover the case.
