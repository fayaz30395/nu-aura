# faylo-skill-slo-sli

Auto-loads for `faylo-sre-engineer` at Stage 13. An SLO needs a measurable SLI behind it (drawn from the instrumentation `faylo-data-engineer` added at Stage 12) and an error budget — a target with nothing measurable behind it is not yet an SLO.
