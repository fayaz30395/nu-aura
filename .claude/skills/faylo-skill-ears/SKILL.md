# faylo-skill-ears

Auto-loads for `faylo-prd-creator` at Stage 03 and `faylo-qa-reviewer` at Stage 11. Every acceptance criterion is either a WHEN-trigger, an IF-condition, or a SHALL-NOT regression guard — never a vague "should work correctly." Stage 11 verification checks pass/fail per criterion precisely because Stage 03 wrote them in this form.
