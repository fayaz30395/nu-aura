# faylo-skill-cloud-infra

Auto-loads for `faylo-cloud-engineer` at Stage 12, which most tickets skip entirely. A new queue, managed database, or scaling-policy change goes through this agent; a ticket that fits inside existing infrastructure does not need it invoked at all.
